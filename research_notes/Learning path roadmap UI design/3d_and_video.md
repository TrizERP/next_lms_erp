# 3D/Isometric Treatments and Video Walkthroughs of Learning Path / Game-Level-Select Map UI

## What are the best known examples of "Duolingo-style" learning path UI, and are there design breakdowns, clones, or tutorials of this pattern?

### Takeaway
Duolingo's own "Path UI" (vertical winding S-curve of circular nodes, one node per lesson/crown-level, built on spaced-repetition sequencing) is the reference implementation and is extensively documented and critiqued by Duolingo itself and by UX writers; it has also been cloned multiple times as open-source code (React/Next.js) that can be read or run directly to see the winding-path component.

### Cited Findings
- Duolingo's official design post describes the home screen as "a path that you'll follow step by step," where each circle equals one crown level of a skill, stories are built into the path (no longer a separate tab), and tips live in a per-unit "guidebook" — ordering is grounded in spaced-repetition learning science. — [Duolingo blog: New Duolingo Home Screen Design](https://blog.duolingo.com/new-duolingo-home-screen-design/)
- A UX critique piece argues the Path UI removed the old "tree" choice-based navigation and forces a single linear sequence, which drove significant user backlash despite the visual appeal of the winding path. — [uxdesign.cc: "Down the Wrong Path"](https://uxdesign.cc/down-the-wrong-path-the-disaster-of-the-latest-duolingo-ui-update-a4cdd1e6ea1c)
- A design/growth case-study newsletter claims the path-based redesign correlated with a 40% engagement surge, framing the winding path as a gamification/retention device, not just decoration. — [Designfolio Substack: "Crazy UX redesign, Duolingo's engagement surge by 40%"](https://designfolio.substack.com/p/crazy-ux-redesign-duolingo)
- A UX case study walks through how user research (usability testing, SWOT) fed into Duolingo's path/lesson-flow design decisions. — [UX Planet: "Duolingo — Translating User Research Into Improved Design"](https://uxplanet.org/duolingo-translating-user-research-into-improved-design-e3e47d2b41ba)
- Open-source clone of the winding path pattern, built with React, TypeScript, Next.js, Tailwind, and Zustand; has a live deployed demo you can interact with directly. — [GitHub: bryanjenningz/react-duolingo](https://github.com/bryanjenningz/react-duolingo) · [Live demo](https://react-duolingo-clone.vercel.app/)
- A second full-featured clone (admin dashboard, Stripe premium, Google SSO) built with Next.js/TypeScript/TailwindCSS/ShadCN/Drizzle/Neon — useful as a second code reference for the path component plus surrounding app shell. — [GitHub: RikhiSingh/Duolingo-Clone](https://github.com/RikhiSingh/Duolingo-Clone)
- Dribbble shot explicitly built "Duolingo-style" for a competitive-exam ed-tech app — shows the winding-node-path pattern adapted to a non-language subject. — [Dribbble: "Duolingo-style education app for competitive exams" by Roopal Gupta](https://dribbble.com/shots/24672857-Duolingo-style-education-app-for-competitive-exams)
- Another Dribbble shot explicitly labeled "Inspired by Duolingo App," part of a multi-shot educational-app series. — [Dribbble: "Educational App Part 3 — Inspired by Duolingo App"](https://dribbble.com/shots/25249861-Educational-App-Part-3-Inspired-by-Duolingo-App)
- Dribbble's tag/search pages aggregate many more Duolingo-pattern shots for browsing (not single examples, but a shopping-list entry point). — [Dribbble tag: duolingo_app](https://dribbble.com/tags/duolingo_app) · [Dribbble search: duolingo-app](https://dribbble.com/search/duolingo-app)

### Inferences
- The pattern is popular enough that it has moved from "Duolingo's proprietary design" to a genre with its own name ("Duolingo-style path"/"path UI") that other ed-tech products now explicitly brand their clones after, per the Dribbble shot titles.
- Because full open-source clones exist and run live, a developer can inspect real component code/CSS for the winding-S-curve node layout rather than reverse-engineering it from screenshots alone.

### Gaps
- I could not find a dedicated, well-known "design breakdown" article (e.g., a Nielsen Norman or Pttrns-style teardown) that annotates the exact SVG/path math Duolingo uses for the S-curve itself — the sources found cover UX rationale and reception, not a geometry/implementation teardown of Duolingo's own code (which is proprietary/obfuscated).

## What game-level-select-map UI patterns exist that could inspire an education roadmap, and are there good references/examples?

### Takeaway
Game level-select/world-map UI is a well-documented genre with real developer devlogs explaining the exact design requirements (nodes connected by a path, locked/unlocked states, per-level stats) that map almost one-to-one onto an education roadmap's needs, plus numerous Dribbble shots showing the isometric/3D "world map with stages" visual treatment.

### Cited Findings
- A detailed indie-dev devlog on redesigning a level-select screen from plain buttons into a map-like interface states the explicit requirements: "displaying level groups as nodes connected through a path in a landscape," buttons per level with locked/unlocked states, high scores on the selected level, and back/play buttons — this reads directly as a spec for an education path UI. — [itch.io devlog: "Designing a Level Select Interface" (Geodessey)](https://feitizogames.itch.io/geodessey/devlog/56371/designing-a-level-select-interface)
- A GameDev.net piece walks through building a "highly customizable, mobile-friendly HTML5 level selection screen," i.e., an implementation-level tutorial for the same node/path pattern. — [GameDev.net: Build a Mobile-Friendly HTML5 Level Selection Screen](https://gamedev.net/news/2162-build-a-highly-customizable-mobile-friendly-html5-level-selection-screen/)
- Dribbble shot "Game Level Map With 5 Different Worlds" shows a cartoon-style overworld map with multiple distinct world zones strung together — a direct visual reference for a multi-unit curriculum map (e.g., one "world" per subject/term). — [Dribbble: "Game Level Map With 5 Different Worlds" by wowu](https://dribbble.com/shots/3524199-Game-Level-Map-With-5-Different-Worlds)
- Dribbble shot "Mobile Game Level Map Concept" shows a similar path-through-landscape treatment aimed specifically at mobile screens. — [Dribbble: "Mobile Game Level Map Concept" by Graphic Assets](https://dribbble.com/shots/3622551-Mobile-Game-Level-Map-Concept)
- Dribbble aggregation/tag pages exist specifically for this genre, useful as browse-and-pick entry points: "Level Map," "Level Selection," and "Level Select Screen." — [Dribbble tag: level_map](https://dribbble.com/tags/level_map) · [Dribbble tag: level-selection](https://dribbble.com/tags/level-selection) · [Dribbble tag: level-select-screen](https://dribbble.com/tags/level-select-screen)
- A Dribbble collection curated around a tower-defense game's "Legends TD World Map UI" shows an isometric/vector world-map style used as game navigation, illustrating the 3D-leaning end of this genre. — [Dribbble collection: "Quests" (incl. Legends TD World Map UI) by travisgregory](https://dribbble.com/travisgregory/collections/2001951-Quests)
- Design-tip commentary on level-select menus notes practical UI rules transferable to an education roadmap: reserve high contrast for selected/interactive nodes only, and consider spiral/golden-ratio layouts to make node selection feel intuitive rather than arbitrary. — summarized from search results citing itch.io/GameDev.net sources above (no separate standalone article URL found beyond those two).

### Inferences
- Game level-select maps are the strongest source genre for a 3D/isometric treatment specifically, since "world map with zones/levels" is routinely rendered isometrically in actual shipped games and Dribbble concept work, whereas education products overwhelmingly stay flat (per the previous question's gap) — so a developer wanting a 3D learning path should mine this category's references more than education-specific ones.
- The devlog-level requirements (nodes + connecting path + lock state + per-node stats + back/play controls) are a near-exact structural match for "completed/current/locked" education milestones, meaning the mapping from game UI to ed UI is mostly a re-skin, not a re-architecture.

### Gaps
- Stock-asset marketplaces (Adobe Stock) also returned many "game level indicator on map UI" isometric assets, but these are purchasable templates, not named design case studies, so they were not included as primary citations — flagged here only as a note that purchasable isometric level-map asset packs exist in volume if the developer wants ready-made art rather than custom design.
