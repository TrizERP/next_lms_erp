## Known gap found and fixed during Phase 3 (not originally scoped, surfaced by testing)

`ai_audit_logs` on the live remote dev database was missing two columns a migration in this repo was
meant to add, silently degrading **every** existing `AiAuditLogger::record()` caller to log-only since
that migration was written. Confirmed via reproduction (not inferred), fixed by running the single
already-authored migration after user approval. Full evidence trail in `K12_IMPLEMENTATION.md`. This is
exactly the class of defect master-prompt rule #9 ("verify through actual code paths, tests, and runtime
evidence") exists to catch — it would not have been visible from reading code alone.
